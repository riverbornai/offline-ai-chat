# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes     |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability in this project, please report it responsibly:

1. Go to the [GitHub Security Advisories](https://github.com/riverbornai/offline-ai-chat/security/advisories/new) page
2. Click **"New draft security advisory"**
3. Fill in the details — description, impact, and reproduction steps

We will respond within **72 hours** and work with you to fix the issue before public disclosure.

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (if any)

## Notes

This app is designed to be fully **offline and privacy-first** — no user data is sent to any server. However, vulnerabilities in on-device model loading, file handling, or native modules are still important to report.

Thank you for helping keep this project secure! 🔒
